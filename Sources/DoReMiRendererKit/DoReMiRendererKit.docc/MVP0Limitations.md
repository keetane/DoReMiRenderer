# MVP0 Limitations

MVP0 is not a complete notation engine.

- MusicXML support is a minimal `score-partwise` subset.
- MXL support is limited to standard unencrypted `META-INF/container.xml`
  rootfile flow.
- Publishing-quality engraving and complex collision avoidance are not
  implemented.
- Snapshot tests, zoom and scroll transforms, complex selection, and audio
  playback are not implemented.

See the repository `MVP0_LIMITATIONS.md` file for the maintained limitation list.
