# DoReMiRenderer Web Canvas Viewer

This example renders a `ScoreWebRenderPlan` in a browser Canvas. It consumes the
JSON coordinates generated by DoReMiRendererKit; it does not parse MusicXML or
recompute score layout in JavaScript.

Generate a plan:

```sh
swift run DoReMiRendererWebExport \
  --input ../../Apps/DoReMiPalette/DoReMiPalette/Resources/Samples/Ode_to_Joy_Easy_variation.mxl \
  --output score-web.json \
  --width 1024
```

Copy `Sources/DoReMiRendererKit/Resources/Fonts/Bravura.otf` beside `index.html`
when hosting this example, and preserve the accompanying SIL OFL notice. Serve
the directory with any static HTTP server and open `index.html`.

The viewer waits for Bravura before its first Canvas draw and displays a visible
error if the font is unavailable. SMuFL notation uses private-use Unicode values,
so a browser fallback font would otherwise show missing-glyph boxes.

The bridge is browser-transport compatible today. Direct client-side Swift/Wasm
parsing and layout will require a future extraction of CoreGraphics/CoreText and
SwiftUI adapters from the package target; the browser must not recreate layout
coordinates in the meantime.
